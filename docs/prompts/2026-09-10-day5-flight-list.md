# Day 5 — 航班列表 + 城市搜索匹配 + 毛玻璃下拉
日期：2026-09-10

## 我的 Prompt

> 一、新增"可选航班"列表区域
> 现状：Monitor 采集的数据含 flight_no / airline / price / depart_time，
> 但前端只显示了最低价。请新增"可选航班"区域（放在曲线卡片和 Agent 卡片之间）：
> - 列出该航线该日期的所有航班
> - 每行展示：航司 + 航班号 | 起飞时间 | 价格
> - 按价格从低到高排序，最低价那行加绿色"最低"标签
> - 数据来源：GET /api/routes/{origin}/{destination}/prices?flight_date=YYYY-MM-DD
>
> 二、城市选择改成"搜索式输入"（像搜索引擎）
> 1. 输入中文、拼音、三字码都能匹配（"bei" / "北京" / "BJS" 都命中北京）
> 2. 匹配结果显示在输入框正下方：左侧中文名 + 右侧三字码（灰色小字）
> 3. 支持键盘上下键选择 + 回车确认
> 4. 点击组件外部关闭列表
> 5. 内置至少 20 个主要城市（中文名 / 拼音 / 三字码 / 机场名 / 机场代码）
>
> 三、匹配结果框用 Apple 毛玻璃效果
> - 背景 bg-white/70 + backdrop-blur-xl
> - 边框 1px 半透明白（border-white/40）
> - 阴影 0 8px 32px rgba(0,0,0,0.08)，圆角 16px
> - 选项 hover 时 bg-black/5
> - 页面背景加一层极淡径向渐变（白 → 极浅蓝），让毛玻璃透出层次
>
> 要求：React 自定义组件，Tailwind 样式，不引入 UI 库。

## 模型与设置
- 首选 Claude Opus 5
- Effort: High ｜ Thinking: 开

## Cursor 做了什么
- 新建城市搜索组件（支持中文/拼音/三字码模糊匹配 + 键盘操作 + 点击外部关闭）
- 新建"可选航班"列表组件（按价格升序，最低价高亮）
- 内置城市数据（20+ 城市，含机场名与机场代码）
- 下拉框改为毛玻璃样式，页面背景加径向渐变

## 我如何引导修正
- 原生 `<datalist>` 下拉位置错乱（跑到"开始分析"按钮附近）且无法美化
  → 让 AI 改为 React 自定义下拉组件
- 页面背景是纯色导致毛玻璃效果不明显
  → 让 AI 给页面加极淡径向渐变作为透出层次

## 验证结果
- 城市输入框支持 "bei" / "北京" / "BJS" 三种方式匹配
- 下拉列表以毛玻璃样式出现在输入框正下方
- 点击「开始分析」后，航班列表按价格升序展示，最低价有绿色标签

## 亮点
1. **交互升级**：从"固定下拉"升级为"搜索引擎式输入"，支持三种匹配方式
2. **视觉精度**：毛玻璃效果需要"背后有内容"才成立，因此配套加了背景渐变
   —— 体现对视觉原理的理解
3. **业务完整性**：从"只知道最低价"到"能看到具体该买哪个航班"
